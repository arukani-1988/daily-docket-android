# Daily Docket for Android

Personal docket for meetings, tasks, follow-ups and hard deadlines.

- **One tap to speak**: the green "Speak" home-screen icon (or widget) starts listening at once, understands the sentence on the phone, saves it and confirms with a notification (Undo / Edit).
- Morning briefing 7:30 am, evening wrap-up 7:00 pm, Monday follow-up report 8:00 am.
- Meeting reminders the evening before and 30 minutes before; deadline warnings 7, 3 and 1 day before and on the day.
- Entries are stored only on the phone.

Each push to `main` builds a signed APK and publishes it under **Releases**.

## Install

Open the latest release on your phone, download `DailyDocket.apk`, and allow installing from your browser when Android asks.
